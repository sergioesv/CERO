OBJETIVO
────────
Corregir el espaciado de los detalles en el drawer de usuarios.

PROBLEMA ACTUAL:
- Labels y valores aparecen pegados: "NombreSergio", "Emailsergio@cero.com"
- Las clases .detail-grid, .detail-item, .detail-label, .detail-value se usan
  en public/modules/usuarios.js pero NO tienen estilos definidos en CSS
- Se renderizan inline sin espacios

SOLUCIÓN:
- Agregar CSS para detail-* en public/css/components.css
- Grid de 2 columnas (label | value) con gap
- Labels en gris secundario, values en color primario


═══════════════════════════════════════════════════════════════════════════════
PASO 1 — Modificar public/css/components.css
═══════════════════════════════════════════════════════════════════════════════

Abrir archivo: public/css/components.css

UBICACIÓN: Después de la línea 292 (.drawer-section-title)

INSERTAR estas líneas:

/* Grid de detalles (usado en drawer de usuarios) */
.detail-grid {
  display: flex;
  flex-direction: column;
  gap: var(--spacing-md);
}
.detail-item {
  display: grid;
  grid-template-columns: 140px 1fr;
  gap: var(--spacing-sm);
  align-items: start;
}
.detail-label {
  font-size: var(--font-size-sm);
  color: var(--text-secondary);
  font-weight: var(--font-weight-medium);
}
.detail-value {
  font-size: var(--font-size-sm);
  color: var(--text-primary);
  word-break: break-word;
}

RESULTADO: El CSS queda insertado después de .drawer-section-title y antes de /* Novedades */

NOTAS
═══════════════════════════════════════════════════════════════════════════════

- Este CSS es reutilizable — si otros módulos (conductores, vehículos, etc.)
  usan las mismas clases detail-*, heredarán automáticamente este estilo
  
- El grid-template-columns de 140px es suficiente para los labels actuales
  ("Ultimo acceso" es el más largo con ~120px)
  
- word-break: break-word evita que emails largos rompan el layout
