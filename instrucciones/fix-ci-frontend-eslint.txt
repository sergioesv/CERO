OBJETIVO
────────
Corregir el fallo del workflow frontend.yml en GitHub Actions.

PROBLEMA ACTUAL:
- eslint.config.cjs ignora public/** en línea 5
- .github/workflows/frontend.yml intenta ejecutar ESLint sobre public/js/, public/components/, public/modules/
- ESLint responde "all files matching the glob pattern are ignored" y sale con exit code 2
- El workflow queda en rojo aunque el código esté bien

SOLUCIÓN:
- Quitar public/** del array de ignores
- Cambiar sourceType de 'commonjs' a 'script' para código frontend
- Agregar globals.browser para variables globales del navegador (window, document, etc.)

Este fix permite que ESLint linte el código frontend correctamente.


═══════════════════════════════════════════════════════════════════════════════
PASO 1 — Modificar eslint.config.cjs
═══════════════════════════════════════════════════════════════════════════════

Abrir archivo: eslint.config.cjs

REEMPLAZAR líneas 1-26 con este contenido EXACTO:

const js = require('@eslint/js');
const globals = require('globals');

module.exports = [
  { ignores: ['node_modules/**'] },
  js.configs.recommended,
  {
    languageOptions: {
      ecmaVersion: 2022,
      sourceType: 'script',
      globals: {
        ...globals.node,
        ...globals.browser
      },
    },
    rules: {
      // ASCII art / tablas en comentarios (p. ej. canales/whatsapp.js)
      'no-irregular-whitespace': 'off',
      // Base de código existente: avisos hasta poder corregir con calma
      'no-unused-vars': 'warn',
      'no-redeclare': 'warn',
      'no-useless-assignment': 'warn',
      'no-useless-escape': 'warn',
      'no-empty': 'warn',
      'no-prototype-builtins': 'warn',
      'preserve-caught-error': 'warn',
    },
  },
];


CAMBIOS REALIZADOS:
1. Línea 5: quitado 'public/**' del array ignores
2. Línea 10: sourceType cambiado de 'commonjs' a 'script'
3. Líneas 11-14: agregado ...globals.browser para variables del navegador


═══════════════════════════════════════════════════════════════════════════════
PASO 2 — Validar localmente
═══════════════════════════════════════════════════════════════════════════════

Ejecutar desde la raíz del proyecto:

npx eslint public/js/ public/components/ public/modules/ --max-warnings=50

RESULTADO ESPERADO:
- ESLint debe correr sin error de "all files are ignored"
- Puede mostrar algunos warnings (esto es normal en código legacy)
- Exit code debe ser 0 si warnings < 50

Si sale algún error BLOQUEANTE (no warnings), reportar a Sergio antes de commitear.
