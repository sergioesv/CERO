OBJETIVO
────────
Corregir el badge del header que muestra el rol del usuario.

PROBLEMA ACTUAL:
- public/index.html línea 20 tiene hardcodeado: <div class="header-user">Administrador</div>
- Nunca se actualiza con el rol real del usuario logueado
- Usuario con rol 'supervisor' ve "Administrador" incorrectamente

SOLUCIÓN:
- Agregar función App.actualizarHeaderUsuario() que lea el JWT y actualice el badge
- Llamarla desde App.init() después de Sidebar.render()
- Capitalizar y traducir nombres de roles correctamente


═══════════════════════════════════════════════════════════════════════════════
PASO 1 — Modificar public/js/app.js
═══════════════════════════════════════════════════════════════════════════════

Abrir archivo: public/js/app.js

UBICACIÓN: Después de la línea 32 (antes de debeCambiarPassword())

INSERTAR estas líneas:

  actualizarHeaderUsuario() {
    const headerUser = document.getElementById('header-user');
    if (!headerUser) return;

    const token = sessionStorage.getItem('cero_token');
    if (!token) {
      headerUser.textContent = 'Usuario';
      return;
    }

    try {
      const base64 = token.split('.')[1].replace(/-/g, '+').replace(/_/g, '/');
      const payload = JSON.parse(atob(base64.padEnd(base64.length + ((4 - base64.length % 4) % 4), '=')));
      
      const nombre = payload.nombre || 'Usuario';
      const roles = payload.roles || [];
      
      // Tomar el primer rol y capitalizarlo
      let rolDisplay = 'Usuario';
      if (roles.length > 0) {
        const rol = roles[0];
        // Mapeo de roles técnicos a nombres legibles
        const mapeoRoles = {
          'superadmin_plataforma': 'Superadmin',
          'superadmin_emp': 'Superadmin Empresa',
          'administrador': 'Administrador',
          'supervisor': 'Supervisor',
          'conductor': 'Conductor',
          'mantenimiento': 'Mantenimiento',
          'sst': 'SST',
          'auditor_interno': 'Auditor Interno',
          'auditor_externo': 'Auditor Externo',
          'reportes': 'Reportes'
        };
        
        rolDisplay = mapeoRoles[rol] || rol.charAt(0).toUpperCase() + rol.slice(1).replace(/_/g, ' ');
      }
      
      headerUser.textContent = rolDisplay;
      headerUser.title = `${nombre} · ${rolDisplay}`;
    } catch (e) {
      console.error('Error actualizando header usuario:', e);
      headerUser.textContent = 'Usuario';
    }
  },

RESULTADO: La función queda insertada entre init() y debeCambiarPassword()
