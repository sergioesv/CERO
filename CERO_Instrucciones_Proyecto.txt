1. METODOLOGÍA DE TRABAJO
================================================================================

El proyecto CERO se desarrolla con dos herramientas de IA coordinadas:

CLAUDE (chat) — Consultor senior de diseño y arquitectura
  - Diseña la solución completa antes de escribir código
  - Mantiene el contexto total del proyecto (12 sesiones de diseño)
  - Toma decisiones de arquitectura, flujo, UX y legales
  - Genera documentos de sesión de diseño (propiedad intelectual)
  - Genera instrucciones precisas para Claude Code
  - Revisa código implementado, diagnostica errores
  - Si necesita ver un archivo del repo, lo pide a Sergio

CLAUDE CODE — Ejecutor de código conectado a GitHub
  - Recibe instrucciones específicas de Claude (chat)
  - Implementa los cambios en el código
  - Ejecuta directamente en el repo (rama activa)
  - Despliega automáticamente vía Railway
  - NO toma decisiones de diseño por su cuenta
  - NO cambia arquitectura sin instrucciones explícitas

FLUJO DE TRABAJO:
  1. Sergio plantea el problema/necesidad en Claude (chat)
  2. Claude diseña la solución, la cuestiona, la refina
  3. Claude genera instrucciones detalladas (BUSCAR/REEMPLAZAR,
     archivos nuevos, SQL, etc.)
  4. Sergio copia las instrucciones y las pega en Claude Code
  5. Claude Code implementa y despliega
  6. Sergio prueba (WhatsApp, panel web, logs Railway)
  7. Si hay errores, Sergio reporta en Claude (chat)
  8. Claude diagnostica y genera instrucciones de corrección
  9. Se repite hasta que funcione

REGLA CLAVE: Claude Code no debe inventar diseño. Si algo no está
claro en las instrucciones, debe preguntar — no adivinar.

8. SISTEMA DE AUTORIZACIÓN DE NOVEDADES (v12)
================================================================================

Flujo:
  1. Operario reporta novedad en ítem crítico
  2. Si el ítem tiene sub-pregunta → bot pregunta precisión
  3. Sistema clasifica: INFORMATIVO / ALERTA / BLOQUEO
  4. Si hay BLOQUEO → supervisor notificado por WhatsApp
  5. Supervisor responde: AUTORIZAR PLACA / TALLER PLACA / RESTRINGIR PLACA
  6. Si AUTORIZAR → pide justificación (mín 10 caracteres)
  7. Decisión registrada con timestamp y justificación
  8. Operario notificado de la decisión

Ítems con sub-pregunta (7):
  Aceite motor, Refrigerante, Líquido frenos, Fugas visibles,
  Pito y alarma reversa, Estado llantas, Pernos de ruedas

Ítems binarios que bloquean (6):
  Luces, Stops/direccionales, Freno parqueo,
  Cinturones, Retrovisores, Pedales (freno)

Ítem que nunca bloquea: Equipo carretera (solo alerta)
